# Minesweeper

A modern, offline-friendly Minesweeper game built with vanilla HTML, CSS, and JavaScript.

## How to run

1. Open `index.html` in your browser, **or**
2. Serve locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Classic Minesweeper rules with safe first click.
- Difficulty presets plus custom board sizes.
- Timer, mine counter, and flag counter.
- Touch support for long-press flagging.
